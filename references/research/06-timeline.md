# 王小波：职业时间线与生平

> 本文档整理王小波（1952-1997）的完整职业时间线，涵盖教育、职业、创作、出版及身后影响。
> 信息来源：Wikipedia (EN/ZH)、纽约时报书评 (2022)、China Perspectives 学术期刊、各种公开传记资料。

---

## 一、早年经历（1952-1977）

| 时间 | 事件 | 备注 |
|------|------|------|
| 1952年5月13日 | 生于北京 | 家庭出身知识分子家庭，父亲为逻辑学和教育工作者 |
| 1968-1970年 | 作为知青下放云南生产建设兵团 | 这段经历后来成为《黄金时代》《革命时期的爱情》等作品的核心素材 |
| 1971年 | 转至山东烟台牟平插队 | 后任民办教师 |
| 1972年 | 回北京，进入北京牛街教学仪器厂工作 | |
| 1973-1974年 | 创作《绿毛水怪》（手稿） | 这是目前所知王小波最早的文学作品，被视为其"文学处女作" |
| 1974年 | 调入北京西城区半导体器件厂 | 工厂经历后来成为《革命时期的爱情》的写作背景 |
| 1977年 | 结识《光明日报》编辑李银河 | 两人因文学结缘 |

## 二、大学教育与早期写作（1978-1984）

| 时间 | 事件 | 备注 |
|------|------|------|
| 1978年 | 考入中国人民大学贸易经济系（商品学专业） | "文革"后恢复高考的第一批大学生 |
| 1980年 | 与李银河结婚 | |
| 1980年 | 发表处女作《地久天长》（《丑小鸭》杂志） | 严格意义上的首次公开发表作品 |
| 1982年 | 从中国人民大学本科毕业 | |
| 1982年 | 留校任教于中国人民大学 | 同年开始写作《黄金时代》初稿 |

## 三、留美时期（1984-1988）

| 时间 | 事件 | 备注 |
|------|------|------|
| 1984年 | 赴美国匹兹堡大学东亚研究中心攻读硕士学位 | 李银河同期在该校攻读社会学博士 |
| 1984-1988年 | 师从历史学家许倬云 | 许倬云对其学术思想和小说创作（尤其是唐代传奇题材的小说）产生深远影响 |
| 1984-1988年 | 在美期间以编程、数据处理等方式勤工俭学 | 这是王小波最早接触编程的时期 |
| 1986年暑假 | 游历西欧 | |
| 1988年 | 获得硕士学位 | 同年与李银河回国 |

## 四、回国任教（1988-1992）

| 时间 | 事件 | 备注 |
|------|------|------|
| 1988-1989年 | 任教于北京大学社会学研究所 | 讲师 |
| 1989-1991年 | 任教于中国人民大学会计系 | 讲师 |
| 1991年 | 《黄金时代》获台湾联合报文学奖中篇小说大奖 | 许倬云将手稿推荐给联合报文学奖评委 |
| 1992年 | 《黄金时代》在台湾联经出版公司首次正式出版 | 大陆出版仍困难重重 |
| 1992年 | 从中国人民大学辞职，成为自由撰稿人 | 在当时极为罕见的职业选择 |

## 五、自由作家时期（1992-1997）

### 职业状态
- 主要身份：自由作家 / 程序员
- 经济来源：编写商业软件程序 + 报刊杂文稿费
- 技术能力：熟练掌握汇编语言和 C 语言，曾开发汉字输入法和数据库管理系统
- 文学发表平台：《读书》《南方周末》《三联生活周刊》《东方》等

## 六、逝世与身后影响（1997至今）

| 时间 | 事件 | 备注 |
|------|------|------|
| 1997年4月11日 | 因突发心脏病逝世于北京 | 年仅44岁 |
| 1997年 | 花城出版社推出"时代三部曲" | 引发"王小波热" |
| 1997年 | 《东宫·西宫》入围戛纳电影节 | 王小波未能亲眼目睹 |
| 1998年 | 《爱你就像爱生命》（与李银河书信集）出版 | 李银河整理 |
| 1998年 | 《绿毛水怪》等早期作品收入文集首次正式出版 | |
| 2000年代 | "王小波门下走狗"现象在互联网上兴起 | 早期BBS、天涯社区形成粉丝文化 |
| 2016年 | 《黄金时代》英译本由 Astra House 出版 | 译者 Yan Yan |
| 2022年7月 | 《纽约时报》发表《黄金时代》英译本书评 | 标题："Sex Confessions and Protest From a Disillusioned Communist"，作者 Ian Johnson |
| 至今 | "王小波热"持续不断 | 被视为中国当代文化史上最持久的文学现象之一 |

## 八、身份标签

王小波身上最独特的标签是多重身份的叠加：

| 身份 | 时间段 | 说明 |
|------|--------|------|
| 知青 / 工人 | 1968-1977 | 下放云南，后在北京工厂工作 |
| 大学生 | 1978-1982 | 中国人民大学贸易经济系 |
| 大学教师 | 1982-1992 | 先后人大学、北大、人大任教 |
| 留学生 | 1984-1988 | 匹兹堡大学东亚研究中心硕士 |
| 程序员 | 1980年代末-1997 | 自学编程，以编写商业软件谋生 |
| 自由作家 | 1992-1997 | 辞职后以写作为主业 |
| 编剧 | 1996 | 《东宫·西宫》 |

王小波曾说写代码和写小说有相通之处——都是用逻辑构建一个世界。这种"作家+程序员"的双重身份在当代中国文学史上独一无二。
